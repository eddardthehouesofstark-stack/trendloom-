# TrendLoom - Fashion Intelligence Dashboard

A sophisticated fashion intelligence platform that helps decision-makers turn market signals into confident production decisions with real-time global intelligence.

## Features

- **Dashboard**: Executive overview with KPIs, action board, and trending insights
- **Explore Trends**: Discover emerging fashion trends globally
- **Seasonal Intelligence**: Seasonal trend analysis and predictions
- **Regional Demand**: Localized design trends with country/state filtering
- **Competitor Trends**: Track competitor movements and market positioning
- **Recommendations**: AI-powered production recommendations
- **Attribute Analyzer**: Deep dive into fashion attributes and characteristics

## Tech Stack

- HTML5
- Tailwind CSS
- Google Fonts (Inter, Playfair Display)
- Material Symbols Icons

## Pages

1. `dashboard.html` - Main executive dashboard
2. `exploretrens.html` - Trend exploration interface
3. `seasonal.html` - Seasonal intelligence analysis
4. `regional.html` - Regional demand with country/state selectors
5. `comp.html` - Competitor trends tracking
6. `suggestion.html` - AI recommendations
7. `attributes.html` - Attribute analyzer

## Deployment

### Vercel (Recommended)
1. Push code to GitHub
2. Import repository in Vercel
3. Deploy automatically

### GitHub Pages
1. Go to repository Settings > Pages
2. Select branch and `/frontend` folder
3. Save and deploy

## Local Development

Simply open any HTML file in your browser. No build process required.

## Design System

- **Primary Colors**: Navy (#0a192f), Teal (#0D9488)
- **Typography**: Playfair Display (headings), Inter (body)
- **Layout**: Consistent sidebar navigation across all pages
- **Components**: Glass-card styling with grain overlay effects
